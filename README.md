# DFA Transition Table Generator (DFATT)

DFATT is a tool which generates a User friendly DFA(Deterministic Finite Automaton) Transition Table from the DFA generated by Flex tool.


## How it works

A lexer `table_lexer.c` is used to extract the DFA table from the required `.yy.c` file. This table is stored in a header file and the main driver code for traversing the DFA is used to generate the required transition table.


[]()


## Usage

Takes the file generated by Flex (.yy.c) as an argument and outputs the Transition Table.

```bash
./dfatt.sh sample.yy.c
```
